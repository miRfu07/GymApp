# Gym Tracker - Android приложение для спортзала

## Описание
Полнофункциональное Android-приложение для отслеживания тренировок в спортзале.

## Функции
- ✅ Создание и редактирование тренировок
- ✅ Добавление упражнений с автоматическим расчетом тоннажа
- ✅ Поддержка формата повторов: 3x10, 3*10 или 3х10
- ✅ Запуск тренировки с общим таймером
- ✅ Индивидуальные таймеры для каждого подхода
- ✅ Возможность запуска нескольких таймеров одновременно
- ✅ История тренировок с датами, тоннажом и временем
- ✅ Удаление тренировок и записей истории
- ✅ Красивая анимация завершения тренировки

## Технологии
- Kotlin
- Jetpack Compose (Material 3)
- Room Database
- Navigation Component
- Coroutines & Flow

## Как собрать APK

### Вариант 1: Использование Android Studio (рекомендуется)
1. Установите Android Studio: https://developer.android.com/studio
2. Откройте проект (папка GymApp)
3. Подождите синхронизации Gradle
4. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s)
5. APK будет в папке `app/build/outputs/apk/debug/`

### Вариант 2: Командная строка (требуется Android SDK)
```bash
cd GymApp
gradlew assembleDebug
```

### Вариант 3: Онлайн сборка
Загрузите проект на GitHub и используйте GitHub Actions или другие CI/CD сервисы для автоматической сборки.

## Использование приложения

### Создание тренировки
1. Нажмите "Добавить новый день тренировки"
2. Введите название тренировки
3. Добавьте упражнения с помощью кнопки "Добавить упражнение"
4. Заполните поля:
   - Название упражнения
   - Повторы (например: 3x10 или 3*10)
   - Вес в кг
   - Тоннаж рассчитается автоматически
5. Сохраните тренировку

### Выполнение тренировки
1. Нажмите "Начать тренировку"
2. Выберите тренировку из списка
3. Запустится общий таймер тренировки
4. Для каждого упражнения:
   - Нажмите "Начать" для подхода
   - Выполните упражнение
   - Нажмите "Стоп" после завершения
5. Можно запускать несколько таймеров одновременно
6. Нажмите "Завершить тренировку" по окончании
7. Появится поздравительное сообщение!

### История
- Просмотр всех завершенных тренировок
- Информация о дате, времени и тоннаже
- Детали упражнений (раскрывающийся список)
- Удаление записей из истории

### Управление тренировками
- Редактирование существующих тренировок
- Удаление тренировок
- Просмотр списка всех тренировок

## Системные требования
- Android 7.0 (API 24) или выше
- ~20 МБ свободного места

## Примечания
- Все данные хранятся локально на устройстве
- База данных Room обеспечивает быструю работу
- Приложение работает офлайн
