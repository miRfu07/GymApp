## ✅ ЧТО ИСПРАВЛЕНО

### 1. Поддержка разных весов для подходов

**Проблема:** Можно было указать только один вес для всех подходов.

**Решение:** Теперь поддерживаются следующие форматы:

#### Формат записи веса:
- **Один вес:** `60` → все подходы по 60 кг
- **Два веса:** `60-65` → первая половина подходов 60 кг, вторая половина 65 кг
  - Пример: 4 подхода → 2×60кг + 2×65кг
- **Несколько весов:** `60-65-70-75` → каждый подход со своим весом
  - Пример: 4 подхода → 60кг, 65кг, 70кг, 75кг

#### Примеры:
```
Упражнение: Жим лежа
Повторы: 4x10
Вес: 60-65-70-75

Результат:
- Подход 1: 60 кг
- Подход 2: 65 кг
- Подход 3: 70 кг
- Подход 4: 75 кг

Тоннаж: (60+65+70+75) × 10 = 2700 кг
```

```
Упражнение: Приседания
Повторы: 4x8
Вес: 80-100

Результат:
- Подход 1: 80 кг
- Подход 2: 80 кг
- Подход 3: 100 кг
- Подход 4: 100 кг

Тоннаж: (80+80+100+100) × 8 = 2880 кг
```

#### Изменения в коде:
- `Exercise.weight` изменен с `Double` на `String`
- Добавлена функция `parseWeights()` для парсинга весов
- Добавлена функция `getWeightForSet()` для получения веса конкретного подхода
- Обновлен расчет тоннажа для учета разных весов
- В UI теперь отображается вес для каждого подхода отдельно

### 3. Исправление автозапуска таймеров

**Проблема:** При запуске таймера одного подхода автоматически запускались таймеры других подходов с тем же номером в других упражнениях.

**Решение:** Убрана логика автозапуска. Теперь каждый таймер запускается только вручную кнопкой "Начать".

#### Как работает сейчас:
1. Нажимаешь "Начать" на конкретном подходе
2. Запускается таймер только для этого подхода
3. Другие подходы остаются неактивными
4. Можно запускать несколько таймеров одновременно вручную
5. Каждый таймер останавливается кнопкой "Стоп"

#### Изменения в коде:
- Удалена логика автоматического запуска таймеров
- Таймеры создаются только при явном нажатии кнопки "Начать"
- Фильтрация таймеров по `exerciseId` и `setNumber` для точного соответствия

### Алгоритм распределения весов

```kotlin
fun parseWeights(weightStr: String, setsCount: Int): List<Double> {
    val weights = weightStr.split("-").mapNotNull { it.toDoubleOrNull() }
    
    return when {
        // Нет весов → все нули
        weights.isEmpty() -> List(setsCount) { 0.0 }
        
        // Один вес → все подходы с этим весом
        weights.size == 1 -> List(setsCount) { weights[0] }
        
        // Два веса → половина/половина
        weights.size == 2 -> {
            val half = setsCount / 2
            List(half) { weights[0] } + List(setsCount - half) { weights[1] }
        }
        
        // Много весов → по порядку, остальные последним весом
        else -> {
            if (weights.size >= setsCount) {
                weights.take(setsCount)
            } else {
                weights + List(setsCount - weights.size) { weights.last() }
            }
        }
    }
}
```

### Примеры распределения

```

→ [60, 60, 60, 60]

4 подхода, вес "60-80":
→ [60, 60, 80, 80]

5 подходов, вес "60-80":
→ [60, 60, 60, 80, 80]

4 подхода, вес "60-65-70-75":
→ [60, 65, 70, 75]

4 подхода, вес "60-65":
→ [60, 60, 65, 65]

6 подходов, вес "60-70-80":
→ [60, 70, 80, 80, 80, 80]
```

### ⚠️ ВАЖНО: Несовместимость с предыдущей версией

Из-за изменения типа поля `weight` с `Double` на `String`, старые данные несовместимы.

### Что делать:

**Вариант 1: Чистая установка (рекомендуется)**
1. Удалите старую версию приложения
2. Установите новую версию
3. Создайте тренировки заново

**Вариант 2: Обновление базы данных**
Если нужно сохранить данные, добавьте миграцию в `GymDatabase`:

```kotlin
@Database(
    entities = [Workout::class, WorkoutHistory::class],
    version = 2,  // Увеличена версия
    exportSchema = false
)
abstract class GymDatabase : RoomDatabase() {
    // ...
}

// В DatabaseProvider:
val MIGRATION_1_2 = object : Migration(1, 2) {
    override fun migrate(database: SupportSQLiteDatabase) {
        // Создать временную таблицу
        database.execSQL("""
            CREATE TABLE exercises_new (
                id INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
                name TEXT NOT NULL,
                reps TEXT NOT NULL,
                weight TEXT NOT NULL,
                tonnage REAL NOT NULL
            )
        """)
        
        // Скопировать данные, конвертируя weight
        database.execSQL("""
            INSERT INTO exercises_new (id, name, reps, weight, tonnage)
            SELECT id, name, reps, CAST(weight AS TEXT), tonnage
            FROM exercises
        """)
        
        // Удалить старую таблицу
        database.execSQL("DROP TABLE exercises")
        
        // Переименовать новую
        database.execSQL("ALTER TABLE exercises_new RENAME TO exercises")
    }
}

// Применить миграцию:
Room.databaseBuilder(context, GymDatabase::class.java, "gym_database")
    .addMigrations(MIGRATION_1_2)
    .build()
```
