## 📱 Как получить APK файл

### ⚠️ ВАЖНО
Для создания APK файла требуется **Android Studio** с Android SDK.

### Вариант 1: Установить Android Studio (РЕКОМЕНДУЕТСЯ)

1. **Скачайте Android Studio**:
   - Перейдите: https://developer.android.com/studio
   - Скачайте и установите (бесплатно)
   - При первом запуске установятся все необходимые компоненты

2. **Откройте проект**:
   - Запустите Android Studio
   - Выберите "Open"
   - Укажите папку: `D:\Soft\claudeCode\GymApp`
   - Дождитесь синхронизации Gradle (3-5 минут)

3. **Соберите APK**:
   - В меню: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
   - Дождитесь завершения (1-2 минуты)
   - Нажмите "locate" в уведомлении

4. **APK будет здесь**:
   ```
   D:\Soft\claudeCode\GymApp\app\build\outputs\apk\debug\app-debug.apk
   ```

5. **Установите на телефон**:
   - Скопируйте `app-debug.apk` на телефон
   - Откройте файл на телефоне
   - Разрешите установку из неизвестных источников
   - Установите приложение

### Вариант 2: Использовать командную строку

Если Android Studio уже установлен:

```bash
cd D:\Soft\claudeCode\GymApp
gradlew assembleDebug
```

APK будет в: `app\build\outputs\apk\debug\app-debug.apk`

### Вариант 3: Запустить скрипт (Windows)

```bash
cd D:\Soft\claudeCode\GymApp
build-apk.bat
```

Скрипт автоматически найдет Android SDK и соберет APK.

## 🎮 Как пользоваться приложением

### Создать тренировку:
1. Главное меню → "Добавить новый день тренировки"
2. Введите название (например: "День груди")
3. Добавьте упражнения:
   - Жим лежа: 4x10, 80 кг
   - Разводка: 3x12, 20 кг
4. Сохраните

### Выполнить тренировку:
1. Главное меню → "Начать тренировку"
2. Выберите тренировку
3. Для каждого подхода:
   - Нажмите "Начать"
   - Выполните упражнение
   - Нажмите "Стоп"
4. Завершите тренировку
5. Получите поздравление! 🎉

### Посмотреть историю:
1. Главное меню → "История"
2. Просмотрите все тренировки
3. Раскройте детали для подробностей

**Варианты решения:**

1. **Установить Android Studio** (рекомендуется):

2. **Попросить кого-то собрать**:
   - Передайте папку GymApp
   - Человек с Android Studio соберет APK за 5 минут

3. **Использовать онлайн-сервисы**:
   - Загрузите проект на GitHub
   - Используйте GitHub Actions для автоматической сборки
   - Инструкции в INSTALLATION.md
