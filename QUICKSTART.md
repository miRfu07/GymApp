# Быстрый старт - Gym Tracker

## 🎯 Что это?
Android приложение для отслеживания тренировок в спортзале с таймерами, расчетом тоннажа и историей.

## 📱 Как установить на телефон?

### Вариант 1: Если у вас есть Android Studio
1. Откройте Android Studio
2. Откройте папку `GymApp`
3. Build → Build APK
4. Скопируйте APK на телефон и установите

### Вариант 2: Если нет Android Studio
К сожалению, для сборки APK требуется Android SDK. 

**Решения:**
1. Установите Android Studio (бесплатно): https://developer.android.com/studio
2. Или попросите кого-то с Android Studio собрать APK для вас
3. Или используйте онлайн-сервисы сборки (см. INSTALLATION.md)

## 🚀 Возможности приложения

### ✅ Создание тренировок
- Добавляйте упражнения
- Указывайте повторы (3x10, 3*10 или 3х10)
- Вес в килограммах
- Тоннаж считается автоматически

### ✅ Выполнение тренировок
- Общий таймер тренировки
- Таймер для каждого подхода
- Можно запускать несколько таймеров одновременно
- Красивое поздравление после завершения: "Ты красавчик! Хорошо поработал!" 🎉

### ✅ История
- Все завершенные тренировки
- Дата и время
- Общий тоннаж
- Время тренировки
- Детали упражнений

### ✅ Управление
- Редактирование тренировок
- Удаление тренировок
- Удаление записей из истории

## 💡 Примеры использования

### Создание тренировки "День ног"
1. Главное меню → "Добавить новый день тренировки"
2. Название: "День ног"
3. Добавить упражнения:
   - Приседания: 4x10, 100 кг → Тоннаж: 4000 кг
   - Жим ногами: 3x12, 150 кг → Тоннаж: 5400 кг
   - Выпады: 3x15, 40 кг → Тоннаж: 1800 кг
4. Сохранить

### Выполнение тренировки
1. Главное меню → "Начать тренировку"
2. Выбрать "День ног"
3. Для каждого упражнения:
   - Нажать "Начать" для подхода
   - Выполнить упражнение
   - Нажать "Стоп"
4. "Завершить тренировку"
5. Получить поздравление! 🎉
